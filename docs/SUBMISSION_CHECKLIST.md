# Submission Checklist (AIBC 2026 Team-Built Product)

## Preliminary mandatory requirements
- [ ] 3-minute structured video pitch
- [ ] Clear problem and user definition ([PROBLEM.md](PROBLEM.md))
- [ ] AI-native approach: LLM + RAG ([ARCHITECTURE.md](ARCHITECTURE.md))
- [ ] Basic system flow: input -> AI -> output
- [ ] Initial demo, prototype, or workflow
- [ ] Bangla / localization
- [ ] Defined potential impact (KPIs) ([EVALUATION.md](EVALUATION.md))

## Judging rubric (5 x 20 = 100)
1. Innovation and AI-native design
2. Technical excellence and architecture
3. Business value and commercial viability (add a short monetization note: e.g. DAE/NGO licensing, agri-input partners)
4. Global scalability and real-world impact
5. Responsible AI, data sovereignty and presentation

## Common mistakes to avoid
- Idea only, no system thinking
- No clear AI explanation
- Overcomplicating instead of one core use case
- No demo or workflow visualization
- Ignoring real users

## Before submitting
- [ ] All cards verified against sources
- [ ] Test results table filled with real numbers
- [ ] Demo and repo publicly accessible
- [ ] Exact cutoff time confirmed on the portal
